`csharp/grade11/collection-helpers` contains supplied node, list, queue, stack, binary-node and ZipInfo source snippets. They use different exercise namespaces and are intended to accompany the matching examples, not to run as one application. Common helper classes also appear beside exercises that use them, so each exercise remains independent.
