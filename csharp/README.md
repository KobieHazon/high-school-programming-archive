# C# exercises

The console exercises use .NET 10. From the repository root:

```sh
uv run --no-project python csharp/run.py list
uv run --no-project python csharp/run.py build
uv run --no-project python csharp/run.py run csharp/grade11/recursion/arrsum
```

The last command prints `20`. You can also use `dotnet run --project <directory>/Exercise.csproj` directly. Interactive examples read one value per line; press Ctrl+C to stop.

`build` compiles the completed projects, excluding the drafts listed below. Add `--include-reference` to list/build supplied examples too. Buildable means the source compiles, not that every algorithm or input is correct. Some projects demonstrate classes with an empty `Main` method. The behavioral suite exercises selected console programs and data structures.

## Incomplete exercises

- `grade10/basics/humus-9`: Unfinished condition in the price-processing loop.
- `grade11/linked-lists/birthday`: The duplicate-name routine is unfinished and calls a missing method.
- `grade11/binary-trees/binnodequestions`: The tree-level exercise requires the missing InfoLevel class.
- `grade11/objects/createclassex`: The class-generator action has no implementation.

The `problem80` program uses floating-point arithmetic for a 100-digit square-root problem and does not produce an exact solution. The `deque` implementation is an unfinished double-ended queue. These source examples are included for study, not as correct reference implementations.
